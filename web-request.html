基本料金には、 サイト全体の基本的なデザイン調整が含まれます。

・文字

・余白

・カード

・ボタン

・レイアウト

原則として必要な素材は ご依頼者にご用意いただきます。

ご提供いただいた素材については、 ご依頼者がWebサイトへ掲載するために必要な権利を 有しているものとして制作します。

第三者の著作権・肖像権・商標権等を 侵害する素材は使用できません。

制作中の修正について

制作中の軽微な修正は 原則3回程度まで料金内です。

軽微な修正の例

・文章の変更

・画像の差し替え

・色の微調整

・文字サイズの微調整

・余白の調整

・小さな配置変更

「修正1回」は、 一度にまとめていただいた修正内容を 1回として扱います。

軽微な修正に含まれないもの

・デザイン全体の作り直し

・サイト構成の変更

・ページ追加

・機能追加

・ADMIN機能追加

・一度確定した仕様の変更

・完成済みページの大幅な作り直し

上記については、 作業前に追加料金をご案内します。

納品後の修正・保守

軽微な修正

1,000円〜

ページ追加・機能変更・大幅な修正については 内容を確認したうえで料金をご案内します。

納品後の継続的な無料修正・ 無料管理・無料保守は 基本料金には含まれておりません。

必要になった場合のみ その都度ご相談ください。

制作時のコードに原因がある不具合については、 内容を確認したうえで対応します。

納品後にご依頼者本人または第三者が コード・設定・サービス連携等を変更したことで 発生した不具合については、 有料対応となる場合があります。

アカウントについて

GitHub・Cloudflare・Discordなど、 サイト運営に必要な外部サービスのアカウントは 原則として ご依頼者本人に作成・所有 していただきます。

制作時に必要となる初期設定については サポートします。

サイト完成後も、 アカウント・サイトデータ・公開環境は ご依頼者本人が管理できます。

ご依頼者のパスワードを 制作側で恒久的に保管することは 原則として行いません。

各サービスのアカウント停止・障害・ 仕様変更等については、 サービス提供元の規約・対応に準じます。

外部サービス・維持費について

GitHub Pagesなど、 無料範囲で利用できるサービスについては 原則として追加費用は発生しません。

ただし、下記のような費用が必要になる場合は 制作料金とは別に ご依頼者本人の負担となります。

・独自ドメイン

・有料プラン

・有料API

・有料ストレージ

・メールサービス

・その他の有料外部サービス

外部サービスが将来、 料金・仕様・無料プラン等を変更した場合も同様です。

対応環境について

PC・スマートフォンの 一般的な現行ブラウザでの閲覧を想定して制作します。

すべての端末・ブラウザ・OSで 完全に同じ表示になることを 保証するものではありません。

非常に古いブラウザや 特殊な閲覧環境への対応は 基本料金には含まれません。

SEOについて

ページタイトル・説明文・ 基本的なサイト構造など、 通常のWebサイトとして必要な 基本設定を行います。

検索順位・アクセス数・集客・収益等を 保証するものではありません。

本格的なSEO運用・広告運用等は 基本料金には含まれません。

対応できないもの

・通販／決済システム

・会員登録／ログインシステム

・予約システム

・顧客管理システム

・クレジットカード情報を扱う機能

・高度な個人情報管理

・金融関連サービス

・医療情報等を扱うシステム

・大規模Webサービス

・複雑なデータベースシステム

・高度なセキュリティ要件を必要とするシステム

・その他、現在の対応可能範囲を超えるもの

既存機能と見た目や目的が似ていても、 必要な仕組み・処理・安全性が異なる場合は 既存プランには含まれません。

「BLOGが作れるので掲示板も同じ」

「ADMINがあるので予約管理もできる」

「似た機能だから料金内」

という扱いにはなりません。

制作範囲について

制作料金は、 制作開始前に双方で確認した 下記の内容を対象とします。

・ページ

・デザイン

・更新項目

・機能

・サイト構成

制作開始後に追加されたご要望や、 最初に決定した仕様から変更となる内容については 別途料金となる場合があります。

料金表に記載されていない内容が 自動的に無料で追加されることはありません。

「既存機能と似ている」 「少し変更するだけ」 「同じページ内で使う」 といった場合でも、 新しい制作作業が必要な場合は 追加料金となることがあります。

追加料金が発生する場合は、 勝手に作業を進めず 事前に内容と料金をご案内します。

お支払いについて

原則として 銀行振込 でのお支払いとなります。

振込先は、 ご依頼内容・料金確定後に 個別でご案内します。

振込手数料は ご依頼者本人の負担となります。

制作開始前：50％
完成確認後：50％

入金確認前に 制作を開始することはありません。

キャンセルについて

制作開始前のキャンセルについては ご相談ください。

制作開始後、 ご依頼者都合によるキャンセルの場合は、 お支払いいただいた着手金を 原則として返金いたしません。

制作済みの作業量が 着手金の範囲を大きく超えている場合は、 制作済み分について 追加料金をご請求する場合があります。

ご連絡が取れない場合

制作に必要な確認・素材提出・修正確認などについて、 こちらからご連絡した日から 7日間ご返信がない場合は、 制作を一時停止または終了させていただく場合があります。

その場合、 原則としてご依頼者都合による 制作中断として扱います。

お支払いいただいた着手金は 原則として返金いたしません。

長期間ご返信が難しい事情がある場合は、 事前にご相談いただければ対応します。
